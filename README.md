# Sanjaya

Sanjaya is a live agent trajectory viewer for Antigravity and Jetski. In the Mahabharata epic, Sanjaya was granted divine sight by the sage Vyasa to witness and report the battlefield live to the king. Similarly, this sidecar observes autonomous agent executions and visualizes them in real time as an interactive directed acyclic graph, latency timeline, token/context breakdown, and subagent tree inside the Auxiliary Pane.

## Features

- **Graph visualization**: Three distinct zoom levels. *Phases* groups consecutive model steps into cohesive operational blocks (such as explore, edit, execute, delegate, or research). *Turns* displays top-level user inputs along with spawned subagents. *Steps* presents the fine-grained model calls, parallel tool invocations, and child conversations.
- **Latency timeline**: Waterfall view displaying step durations and execution sequences. Compresses long idle gaps between user turns so active work remains clearly visible.
- **Tool usage analytics**: Tabular overview of every tool called, including total invocation counts, error rates, average duration, and aggregate time spent.
- **Token and context breakdown**: Visualizes context growth across model calls, contrasting fresh prompt tokens against cached tokens, tracking response tokens, and indicating context compaction events.
- **Subagent hierarchy**: Recursive tree displaying conductor-to-subagent delegations, roles, step counts, tool calls, and error totals.
- **Notes and annotations**: Save step-level notes or trajectory-wide annotations persisted in the local sidecar data directory.
- **Step inspector**: Deep dive into individual step details, displaying system prompts, chain-of-thought thinking blocks, tool input arguments, raw outputs, and error stack traces read from full log transcripts.
- **Steer and fork**: Send anchored steering instructions to an active conversation, or fork from any previous step by generating a structured handoff prompt.
- **Markdown export**: Export the complete trajectory, phase summaries, tool metrics, and notes as a clean Markdown report.
- **Live follow**: Automatically updates the view as new steps are logged to disk.

## Requirements

- Python 3.9 or higher
- Antigravity or Jetski with UI plugin/extension support enabled
- Zero external Python dependencies (uses the standard library exclusively)

## Install

Run the installer to register the plugin:

```bash
# Install for both Antigravity and Jetski (symlinks plugin directory)
./install.sh

# Install for Antigravity only
./install.sh --target antigravity

# Install for Jetski only
./install.sh --target jetski

# Install to a specific workspace
./install.sh --workspace /path/to/project

# Copy files instead of creating symlinks
./install.sh --copy

# Force overwrite existing installations or broken links
./install.sh --force

# Preview actions without making changes
./install.sh --dry-run

# Uninstall from target locations
./install.sh --uninstall
```

### Opening the Pane

1. Open the Auxiliary Pane in your editor.
2. Select **Sanjaya** from the Extensions menu (+).


## Standalone Development

You can run the sidecar HTTP server independently in a local browser:

```bash
cd sidecars/sanjaya
python3 server.py --port 8765
```

Navigate to:
```
http://127.0.0.1:8765/?conversationId=<id>
```

Replace `<id>` with any valid conversation identifier from your local data directory.

## How It Works

Sanjaya parses JSONL log files generated by the agent runtime:
- `<appDataDir>/brain/<conversation-id>/.system_generated/logs/transcript.jsonl`
- `<appDataDir>/brain/<conversation-id>/.system_generated/logs/transcript_full.jsonl`

Candidate application data directories are discovered dynamically in the following order:
1. Paths specified in the `SANJAYA_APP_DIRS` environment variable (delimited by the platform path separator).
2. The data directory derived from `ANTIGRAVITY_EXECUTABLE_DATA_DIR`.
3. Standard user paths: `~/.gemini/antigravity` and `~/.gemini/jetski`.

## API Reference

The sidecar HTTP server binds to `127.0.0.1` and exposes the following endpoints:

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/conversations` | List recent conversations across all discovered app directories. |
| GET | `/api/meta?id=<id>` | Return transcript existence, size, and modification timestamp. |
| GET | `/api/trajectory?id=<id>` | Return the complete parsed trajectory model (steps, turns, phases, stats). |
| GET | `/api/step?id=<id>&i=<index>` | Return full, untruncated step payload from `transcript_full.jsonl`. |
| GET | `/api/subagents?id=<id>` | Return recursive tree of spawned subagents and their stats. |
| GET | `/api/annotations?id=<id>` | Retrieve trajectory- and step-level annotations. |
| GET | `/api/export?id=<id>` | Generate and download a Markdown summary report. |
| GET | `/api/config` | Return server version, app directories, and CLI bridge availability. |
| POST | `/api/annotations` | Add or delete annotations for a trajectory or specific step index. |
| POST | `/api/fork-prompt` | Generate a structured handoff prompt up to a designated step. |
| POST | `/_sidecar/send-message` | Dispatch guidance into the active session via `agentapi`. |
| POST | `/_sidecar/new-conversation` | Spawn a new conversation thread via `agentapi`. |
| POST | `/_sidecar/get-conversation-metadata` | Query session details via `agentapi`. |

## Filter Syntax

Use the search bar to filter nodes and timeline entries:
- **Free text**: Matches step summaries, tool names, requests, and previews (e.g. `build`).
- **Step number**: Prefix with `#` (e.g. `#12`).
- **Step kind**: `is:error`, `is:tool`, `is:model`, `is:user`, `is:message`, `is:checkpoint`, `is:system`.
- **Category**: `is:explore`, `is:edit`, `is:execute`, `is:delegate`, `is:research`, `is:communicate`.

## Security

- Binds strictly to loopback interface `127.0.0.1`.
- API endpoints and POST routes authenticate requests using `X-Sidecar-Token` or the `token` parameter with constant-time validation (`hmac.compare_digest`).
- Transcripts are accessed read-only; no modification of agent execution logs occurs.
- Annotations are stored separately in `annotations.json` within the sidecar data directory.

## Limitations

- Tool results are paired with invocations sequentially based on completion order.
- Phase boundaries use deterministic heuristics rather than an LLM summarizer.
- Steer appends a new guidance message anchored at a step; it cannot roll back completed actions.
- Fork generates a handoff summary and starts a new conversation from that context.
- Steer and Fork capabilities require the `agentapi` binary to be present on your PATH.
